# Study inputs

Copy [study.example.json](study.example.json) to your working directory and edit the paths. Relative paths resolve from the manifest. Inputs are 3D NIfTI images with valid affines and millimetre units. Supply the scanner minIP under `mip`. SWI alone supports detection; a complete seven-task assessment needs phase and minIP, and the default localization needs magnitude.

## Detection and evidence

~~~sh
python -m pip install '.[detector]'
work_dir=$(mktemp -d)
cmb-dlc validate --study /path/to/study.json
cmb-dlc detect --study /path/to/study.json \
  --checkpoint /path/to/swi_2.5d_v4.pth --runtime "$work_dir" --device cpu
cmb-dlc evidence --study /path/to/study.json --run "$work_dir/<run-id>" \
  --candidate-id '<candidate-id>' --output "$work_dir/assessment"
~~~

The checkpoint is supplied separately and loaded in weights-only mode. Use `cuda:0` to select a GPU. The run manifest gives the run ID, and `candidates.json` gives candidate IDs and scores. Coordinates are native voxel indices and right-anterior-superior (RAS) millimetres. Phase focality is omitted when phase is missing. The minIP focal dot and vessel continuity checks are omitted when minIP is missing. Other supported evidence rows are retained.

Use `assessment/evidence.json` to pair each prompt with its PNG file. Pass the parsed responses to `cmb-dlc score` using the shape generated by [the synthetic example](../examples/synthetic_scores.py). Copy the `available_roles` list from the evidence manifest. A missing response for a declared task stays pending.

~~~sh
cmb-dlc score --input /path/to/assessment-responses.json --threshold 0.392399 \
  > "$work_dir/scores.json"
~~~

The example threshold above is the FDUCMB operating point. Use a validated cutoff for other model outputs.

## Atlas and localization

Install the registration extra and make FreeSurfer SynthStrip available as `mri_synthstrip`. Supply the original MARS parcellation from the published atlas repository and a matching MNI T1 template. The optional native T1 is used when spacing is at most 2 mm in every direction.

~~~sh
python -m pip install '.[registration]'
cmb-dlc register --study /path/to/study.json --mni-template /path/to/mni_t1.nii.gz \
  --mni-atlas /path/to/published_mars_atlas.nii.gz --t1 /path/to/native_t1.nii.gz \
  --output "$work_dir/atlas"
cmb-dlc localize --study /path/to/study.json --run "$work_dir/<run-id>" \
  --candidate-id '<retained-id>' --scores "$work_dir/scores.json" \
  --atlas "$work_dir/atlas/mars_swi.nii.gz" --atlas-labels "$work_dir/atlas/mars_labels.json" \
  --output "$work_dir/location"
~~~

The code fits an affine MNI-to-T1 transform and a rigid T1-to-SWI transform with a suitable T1, or an affine MNI-to-SWI transform otherwise. It transfers labels with ANTs `genericLabel` interpolation. Existing SynthStrip images can be provided through `--swi-brain` and `--t1-brain`. A pre-registered atlas can be used directly if it matches the native SWI grid. Its label mapping follows [mars_labels.example.json](mars_labels.example.json); use `midline_or_uncertain` for an unresolved side.

The localization manifest pairs the two composites with a location-only prompt. The atlas suggestion and proportions in a 2 mm neighborhood supplement the images. Add the parsed location response as `localization` for the retained candidate and rerun `score` to obtain the 26 region-by-side counts. Keep the resulting evidence and responses in your private working directory.
